# Codex Packaging Style Skills

这个仓库包含四个面向包装设计的 Codex skill。它们都用于分析包装设计参考图，提炼视觉风格、包装结构、颜色、图形元素、排版气质和摄影置景逻辑，帮助快速生成同类包装视觉方向。

## Skill 说明

### `styleskill`

`styleskill` 的主要目的是模仿参考包装图的视觉风格，并输出一段可继续编辑的 Image2 中文提示词。

它会先识别参考图中的包装设计信息，再输出两部分内容：

- `User Variable Injection Box`
- 风格复刻提示词

提示词会保留用户可自定义项，方便后续替换品牌、产品、颜色、图形元素和包装形式。可自定义变量包括：

- `[Brand_Name]`：品牌名或品牌气质名称
- `[Product_Name]`：产品类别、主成分或产品语境
- `[Primary_Color]`：包装主体色或核心视觉色块
- `[Main_Element]`：主要图形元素，例如植物线稿、食材插画、纹样、符号等
- `[Packaging_Form]`：包装形式，例如纸盒、礼盒、袋装、瓶身、套装卡盒等

适合用于：先得到一条结构完整、风格明确、仍可手动调整的包装生成提示词。

### `styleskill-flex`

`styleskill-flex` 的主要目的是学习参考包装图的画风，但不照抄参考图里的具体元素。

它会保留 `styleskill` 的整体流程，仍然输出：

- `User Variable Injection Box`
- 风格变体提示词

不同点是：它会把主元素做成“相似但不相同”的变体。比如参考图里是“跑步的兔子”，生成提示词时可以变成“奔跑的兔子”“跳跃的兔子”或同样轻盈动势的其他动物，而不是完全复制“跑步的兔子”。

它学习的重点是：

- 画风和线条语言
- 色彩关系
- 包装表面工艺
- 排版秩序
- 置景和光影
- 整体包装气质

它还会避免明显的知识产权抄袭问题：品牌名、logo、商标、slogan、专属字标和独特图形都必须做原创替换，不能照搬参考图。但这些内容不会被删除，skill 会保留它们原本的位置、排版层级和视觉功能，并根据产品生成新的原创品牌名、标志和短句。

背景和字体也会更贴近参考图：背景会学习参考图的空间关系、光影、台面和整体氛围，但改变局部道具或纹理；字体会模仿参考图的字重、字距、层级、横竖排和风格气质，但替换具体文字。

适合用于：希望保留参考包装的审美方向，但让图形元素更灵活、更有变化，并避免生成结果和参考图过于相同。

### `styleskill-flex-imagegen`

`styleskill-flex-imagegen` 的主要目的是直接生成包装风格变体图。

它基于 `styleskill-flex`，但不会输出提示词。agent 会在内部学习参考图的画风、色彩、工艺、排版和包装气质，然后直接调用图像生成工具出图。

它额外强化了防抄袭规则：遇到品牌名、商标、logo、slogan、专属字标、可识别 IP 角色、版权插画或独特纹样时，必须做模仿替换，不能照搬。生成结果应该是相同风格方向的新包装图，而不是复刻原图的品牌资产或专属元素。

如果参考图里有文字，它会保留文字位置和字体系统，并做同类可读替换：品牌名换新的原创品牌名，产品名换新的同品类产品名，slogan 换新的原创短句，口味、成分、容量和卖点标签换成同类信息；不会把文字变成抽象线条、乱码或伪文字。

适合用于：想快速得到同画风包装设计图，同时避免品牌名、商标、slogan 和独特元素过度一致。

### `styleskill-imagegen`

`styleskill-imagegen` 的主要目的是直接出图。

它同样会分析参考包装图，识别包装设计变量并提炼视觉风格，但不会把提示词展示给用户。agent 会在内部构造提示词，并直接调用图像生成工具，生成一张相同风格方向的新包装图。

适合用于：不想手动编辑提示词，只想根据参考图快速生成同风格包装设计图。

## 四者区别

- `styleskill`：输出可编辑提示词，保留自定义变量，适合继续改品牌、产品、颜色和包装形式。
- `styleskill-flex`：输出可编辑提示词，但主元素和品牌资产会做相似变体，保留品牌/logo/slogan 的位置并替换为产品相关原创内容，同时模仿背景和字体风格。
- `styleskill-flex-imagegen`：隐藏提示词，直接生成相似但不照抄的包装风格变体图，并替换高风险品牌元素。
- `styleskill-imagegen`：隐藏提示词，直接生成图片，适合快速获得同风格包装视觉方案。

## 安装位置

将对应文件夹复制到 Codex 默认 skill 目录：

```text
~/.codex/skills/
```

## 使用方式

在 Codex 中上传包装设计参考图后，可分别调用：

```text
$styleskill
$styleskill-flex
$styleskill-flex-imagegen
$styleskill-imagegen
```
